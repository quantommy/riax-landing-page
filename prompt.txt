### 2.1 Navbar (Fixed Position)

**Inspiration: Linear.app navbar + Anthropic.com header**

**Structure:**
```
Logo (left) | [Agents] [Pricing] [Docs] (center-left) | [Sign In] [Try Free] (right)
```

**Specifications:**
- Height: 64px
- Background: `rgba(12, 17, 32, 0.8)` with `backdrop-blur-xl`
- Border bottom: 1px solid `rgba(199, 204, 216, 0.1)`
- Padding: 0 48px (desktop), 0 24px (mobile)
- Logo: 32px height, white text "AURELIUM" in Inter SemiBold
- Nav links: 14px, color `#F8F9FB`, hover → `#ECCE6E` transition 200ms
- Buttons:
  - "Sign In": Ghost button (transparent, border 1px `#C7CCD8`, text `#F8F9FB`)
  - "Try Free": Filled (`#ECCE6E` bg, `#0C1120` text, semibold)
  - Both: 36px height, 16px horizontal padding, 8px border radius

**Interaction:**
- Navbar appears with 300ms fade from top on page load
- On scroll down past 100px: increase backdrop blur and reduce transparency
- Sticky throughout

## 8. Critical Implementation Notes

### 8.1 Performance Requirements

**Bundle Size:**
- Initial load: < 200KB (gzipped)
- Use code splitting for agent-specific code
- Lazy load chart libraries (Recharts) only when needed

**Image Optimization:**
- Use WebP format with JPEG fallback
- Lazy load images below fold
- Use `loading="lazy"` attribute
- Provide low-quality placeholders (LQIP)

**Font Loading:**
```css
/* Prevent FOIT (Flash of Invisible Text) */
font-display: swap;

/* Preload critical fonts */
<link rel="preload" href="/fonts/Inter-Variable.woff2" as="font" type="font/woff2" crossorigin>
```

**Rendering:**
- Use CSS containment for complex components
- Virtualize long lists (react-window)
- Debounce search/filter inputs (300ms)

### 8.2 Accessibility Requirements

**Keyboard Navigation:**
- All interactive elements must be focusable
- Logical tab order throughout
- Visible focus indicators (2px gold outline with offset)
- Escape key closes modals/drawers
- Enter/Space activates buttons

**Focus Indicator:**
```css
:focus-visible {
  outline: 2px solid #ECCE6E;
  outline-offset: 2px;
}
```

**Screen Reader Support:**
- Semantic HTML (nav, main, article, aside)
- ARIA labels for icon-only buttons
- ARIA live regions for dynamic content
- Alt text for all images (even decorative: alt="")
- Form labels properly associated

**Color Contrast:**
- All text meets WCAG AA standards
- Primary text on dark: #F8F9FB (17.8:1 ratio) ✓
- Muted text: #A8B1C4 (8.5:1 ratio) ✓
- Gold accent on dark: #ECCE6E (12.2:1 ratio) ✓

**Reduced Motion:**
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

### 8.3 Browser Support

**Target:**
- Chrome/Edge: Last 2 versions
- Firefox: Last 2 versions
- Safari: Last 2 versions
- Mobile Safari: iOS 14+
- Chrome Mobile: Android 9+

**Fallbacks:**
- Backdrop-filter: Use solid background fallback
- CSS Grid: Use Flexbox fallback
- Custom properties: Provide static values

### 8.4 State Management

**Recommendations:**
- Use Zustand for global state (lightweight)
- React Query for server state
- Local state (useState) for UI-only state

**Key State Slices:**
```javascript
// authStore
- user
- token
- isAuthenticated

// workspaceStore
- currentAgent
- activeTasks
- recentTasks

// uiStore
- sidebarCollapsed
- chatPanelOpen
- activeModal
```

**Network Errors:**

**Full Page Load:**
Centered spinner with logo:

Logo at 48px
Spinner below (32px)
Optional: "Loading..." text (14px muted)


**Component Load:**
- Skeleton loaders matching content shape
- Maintain layout stability (no shifts)

**Button Loading:**
- Replace button text with spinner
- Maintain button width (don't collapse)
- Disable button interaction

**Progressive Enhancement:**
- Show basic content immediately

- Ensure core functionality works without JS (where possible)

## 14. Final Notes for Junior Developers

### 14.1 Common Pitfalls to Avoid

**❌ DON'T:**
- Hardcode colors - always use design tokens
- Use inline styles - use Tailwind classes
- Forget mobile-first approach
- Skip loading states
- Ignore empty states
- Use `div` for everything - use semantic HTML
- Forget keyboard navigation
- Skip error boundaries
- Use `any` in TypeScript
- Commit commented-out code

**✅ DO:**
- Follow the 8px spacing grid religiously
- Test on real devices, not just browser DevTools
- Use semantic HTML (`nav`, `main`, `section`)
- Add ARIA labels where needed
- Implement proper error handling
- Use TypeScript strictly
- Write meaningful commit messages
- Ask questions if specs unclear
- Reference the inspiration sites when stuck
- Measure performance regularly

### 14.2 When in Doubt

**For visual questions:**
1. Check Linear.app first (it's your north star)
2. Then check specific reference for that component type
3. Default to simplicity - less is more

**For interaction patterns:**
1. Ensure it feels smooth (60fps)
2. Transitions should be quick (200-300ms)
3. Hover states should be subtle
4. Mobile taps need immediate visual feedback

export function Button({
  variant = 'primary',
  size = 'md',
  loading = false,
  disabled = false,
  children,
  onClick,
  type = 'button',
  fullWidth = false,
}: ButtonProps) {
  const baseClasses = 'font-semibold rounded-lg transition-all duration-200 ease-out inline-flex items-center justify-center gap-2';

    primary: 'bg-[#ECCE6E] text-[#0C1120] hover:brightness-110 hover:scale-[1.02] active:scale-[0.98]',

    md: 'h-12 px-6 text-base',
    lg: 'h-[52px] px-8 text-base',
  };
  
  const disabledClasses = 'opacity-40 cursor-not-allowed hover:scale-100 hover:brightness-100';
  const widthClasses = fullWidth ? 'w-full' : '';

    ${baseClasses}
    ${variantClasses[variant]}
    ${sizeClasses[size]}

typescript// components/Input.tsx
import { useState } from 'react';
import { AlertCircle, Eye, EyeOff } from 'lucide-react';

interface InputProps {
  label?: string;
  type?: 'text' | 'email' | 'password' | 'number';
  placeholder?: string;
  value: string;
  onChange: (value: string) => void;
  error?: string;
  disabled?: boolean;
  required?: boolean;
  fullWidth?: boolean;
}

export function Input({
  label,
  type = 'text',
  placeholder,
  value,
  onChange,
  error,
  disabled = false,
  required = false,
  fullWidth = true,
}: InputProps) {
  const [showPassword, setShowPassword] = useState(false);
  const [isFocused, setIsFocused] = useState(false);
  
  const inputType = type === 'password' && showPassword ? 'text' : type;
  
  const baseClasses = 'h-12 px-4 rounded-lg font-inter text-[15px] text-[#F8F9FB] placeholder:text-[#A8B1C4] transition-all duration-200';
  const bgClasses = isFocused ? 'bg-[rgba(26,35,52,0.8)]' : 'bg-[rgba(26,35,52,0.5)]';
  const borderClasses = error 
    ? 'border border-[#EF4444]' 
    : isFocused 
      ? 'border border-[#ECCE6E]' 
      : 'border border-[rgba(199,204,216,0.2)]';
  const disabledClasses = disabled ? 'opacity-50 cursor-not-allowed' : '';
  const widthClasses = fullWidth ? 'w-full' : '';
  
  return (
    <div className={`flex flex-col gap-2 ${widthClasses}`}>
      {label && (
        <label className="text-sm font-semibold text-[#C7CCD8]">
          {label}
          {required && <span className="text-[#EF4444] ml-1">*</span>}
        </label>
      )}
      
      <div className="relative">
        <input
          type={inputType}
          value={value}
          onChange={(e) => onChange(e.target.value)}
          onFocus={() => setIsFocused(true)}
          onBlur={() => setIsFocused(false)}
          placeholder={placeholder}
          disabled={disabled}
          required={required}
          className={`${baseClasses} ${bgClasses} ${borderClasses} ${disabledClasses} ${type === 'password' ? 'pr-12' : ''}`}
          aria-invalid={!!error}
          aria-describedby={error ? `${label}-error` : undefined}
        />
        
        {type === 'password' && (
          <button
            type="button"
            onClick={() => setShowPassword(!showPassword)}
            className="absolute right-4 top-1/2 -translate-y-1/2 text-[#A8B1C4] hover:text-[#F8F9FB] transition-colors"
            aria-label={showPassword ? 'Hide password' : 'Show password'}
          >
            {showPassword ? <EyeOff size={20} /> : <Eye size={20} />}
          </button>
        )}
      </div>
      
      {error && (
        <div id={`${label}-error`} className="flex items-center gap-2 text-[#EF4444] text-xs">
          <AlertCircle size={14} />
          <span>{error}</span>
        </div>
      )}
    </div>
  );
}

16.4 Modal Component
typescript// components/Modal.tsx
import { X } from 'lucide-react';
import { useEffect } from 'react';

interface ModalProps {
  isOpen: boolean;
  onClose: () => void;
  title?: string;
  children: React.ReactNode;
  size?: 'sm' | 'md' | 'lg';
}

export function Modal({
  isOpen,
  onClose,
  title,
  children,
  size = 'md',
}: ModalProps) {
  // Close on Escape key
  useEffect(() => {
    const handleEscape = (e: KeyboardEvent) => {
      if (e.key === 'Escape') onClose();
    };
    
    if (isOpen) {
      document.addEventListener('keydown', handleEscape);
      document.body.style.overflow = 'hidden';
    }
    
    return () => {
      document.removeEventListener('keydown', handleEscape);
      document.body.style.overflow = 'unset';
    };
  }, [isOpen, onClose]);
  
  if (!isOpen) return null;
  
  const sizeClasses = {
    sm: 'max-w-md',
    md: 'max-w-2xl',
    lg: 'max-w-4xl',
  };
  
  return (
    <div 
      className="fixed inset-0 z-50 flex items-center justify-center p-4"
      role="dialog"
      aria-modal="true"
      aria-labelledby={title ? 'modal-title' : undefined}
    >
      {/* Overlay */}
      <div 
        className="absolute inset-0 bg-[rgba(12,17,32,0.85)] backdrop-blur-lg animate-fadeIn"
        onClick={onClose}
        aria-hidden="true"
      />
      
      {/* Modal content */}
      <div 
        className={`relative bg-[#1A2334] border border-[rgba(199,204,216,0.2)] rounded-2xl p-10 shadow-[0_20px_60px_rgba(0,0,0,0.4)] animate-scaleIn w-full ${sizeClasses[size]}`}
      >
        {/* Close button */}
        <button
          onClick={onClose}
          className="absolute top-6 right-6 text-[#A8B1C4] hover:text-[#F8F9FB] transition-colors"
          aria-label="Close modal"
        >
          <X size={24} />
        </button>
        
        {/* Title */}
        {title && (
          <h2 id="modal-title" className="text-2xl font-semibold text-[#F8F9FB] mb-6">
            {title}
          </h2>
        )}
        
        {/* Content */}
        <div className="text-[#F8F9FB]">
          {children}
        </div>
      </div>
    </div>
  );
}
